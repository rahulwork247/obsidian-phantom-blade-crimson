## ✨ Features

- **Katana Tab Border:** Subtle crimson blade edge illumination on active tabs.
- **Luminescent Headings:** Headings H1–H6 feature subtle crimson underlines and faint ambient glow.
- **Custom Codeblocks:** Precision borders with syntax highlighting designed for nighttime deep focus.
- **Enhanced Callouts:** Sleek callout cards with crimson blade ribbons.
- **High Performance:** 100% pure CSS, 0 JavaScript overhead, instant loading across desktop and mobile.

## 📥 Installation

### Method A: Obsidian Community Themes (Recommended once indexed)
1. Open Obsidian -> **Settings** -> **Appearance** -> **Themes**.
2. Click **Manage** and search for `Phantom Blade Crimson`.
3. Click **Install and Use**.

### Method B: Manual Installation
1. Locate your Obsidian vault's `.obsidian/themes` directory.
2. Create a folder named `Phantom Blade Crimson`.
3. Copy `manifest.json` and `theme.css` into `.obsidian/themes/Phantom Blade Crimson/`.
4. In Obsidian, go to **Settings** -> **Appearance** -> **Themes** and select `Phantom Blade Crimson`.
